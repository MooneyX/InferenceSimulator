仅支持 DSL；物理页为 64 的正整数因子或倍数，支持多实例或单实例物理 P/D 分离（二者不可叠加）。支持分层缓存、容量恢复和 none / best_effort / timeout / race 预取；到达模型固定 closed，超级块关闭。

[0,T) 按泊松过程投放 session，T 后继续已投放 session，最迟 T+D 停止；并非把模板池完整回放一遍。同 bundle、seed 和投放参数固定 session 计划，completion 后继的实际到达仍受策略执行影响。输出身份 unmapped，完成依赖为推断所得；小页共享保守，输入/输出尾页分别取整，稳定性和理想缓存未评估。

支持当前/全部策略、目标 QPS 与硬件/策略扫描和交叉分析；不支持输入长度、前缀命中、预热、请求数等合成生成维度。配置导出仅含实验设置和 bundle 摘要，导入后需重选核验数据，不是独立可复现包。上传内容不持久化；文件、任务体、请求数、墙钟、页数及结果预算保持服务端限制，超限明确失败。
